# React Powered Shopping Cart

A responsive shopping cart application built using React.js, JavaScript, HTML, and CSS.

## Features

- Product listing
- Product details
- Add products to cart
- Remove products from cart
- Increase and decrease product quantity
- Dynamic price calculation
- Responsive user interface

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
